# Slice 07 — Gallery photo table

## Status

**PLANNED — implementation waits for Slice 06 approval.**

## Purpose

Keep real Manic photography primary while giving the gallery a physical editorial-desk feeling.

## Blender composition

- warm timber tabletop slab
- thin empty photo-card backing geometry
- aged brass spoon
- small flower/stem detail
- subtle coffee-ring relief/stain geometry
- torn menu/paper corner

Actual Manic photographs remain HTML `<img>` elements layered/aligned over the physical card positions rather than baked into GLB textures.

## Static framing

Desktop starts at a restrained angled tabletop view with three photo positions creating overlap and depth. Mobile simplifies to photography-first; decorative Blender props can be reduced or disabled if they compete with the images.

## Motion after static gate

- camera moves gently toward a more top-down contact-sheet view
- one photo position advances slightly
- another rotates only 2–3°
- spoon/flower stay mostly still as scale cues
- no carousel and no auto-advancing content
- reduced motion stays on the approved static table composition
