# Slice 08 — Review paper

## Status

**PLANNED — implementation waits for Slice 07 approval.**

## Purpose

Give the evidence-backed review sentiment a quiet tactile pause between high-energy spatial moments. This is intentionally not another hero scene.

## Blender composition

- one slightly curved off-white receipt/paper card
- subtle folded/creased edge
- small brass clip or spoon fragment as a scale cue
- broad table/chair shadow silhouettes only; no modelled people

Review wording remains HTML. No customer quote is baked into the mesh or texture.

## Static framing

Dark charcoal section. Paper floats only a few millimetres above an implied surface with a tight contact shadow; the headline remains the strongest visual element.

## Motion after static gate

- paper rotates from a slight edge angle toward the approved face-on state
- shadow length changes coherently
- supporting copy settles by a tiny amount
- no endless floating loop
- reduced motion uses the approved face-on static frame
