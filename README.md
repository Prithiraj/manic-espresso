# Manic Espresso

Conversion-focused static website for Manic Espresso, Como WA.

## Live site

GitHub Pages target: `https://prithiraj.github.io/manic-espresso/`

## Structure

- `site/` — static GitHub Pages artifact
- `DESIGN_PLAN.md` — evidence-led design and implementation plan
- `IMAGE_RIGHTS.md` — current image provenance and commercial-launch rights notes
- `.github/workflows/pages.yml` — GitHub Pages deployment

## Local preview

Serve the `site/` directory with any static web server, for example:

```bash
python -m http.server 8080 --directory site
```

Then open `http://localhost:8080`.

## Content baseline

Business details were checked in September 2026. Menu items and external platform availability can change and should be re-verified before an official commercial launch.

## Image note

The preview uses real Manic Espresso business-post imagery mirrored by FindGlocal. See `IMAGE_RIGHTS.md`. Those images should be replaced with owner-controlled originals or formally cleared before commercial launch.
