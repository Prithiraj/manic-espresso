# Image rights / provenance

The GitHub Pages demo intentionally uses **real Manic Espresso photography** rather than generic stock or AI-generated food imagery. The image files are cached inside this repository so the demo does not depend on fragile third-party hotlinks.

> **Demo-only notice:** local caching does not transfer copyright or create a commercial-use licence. These photographs are suitable as temporary design/demo references only unless the relevant rights holder grants reuse permission. Before an official commercial launch, replace them with owner-supplied originals or obtain explicit commercial web rights.

## Superseded hotlinks

The first demo build referenced FindGlocal mirror URLs directly. Those links began returning 404 responses and caused the broken images visible on GitHub Pages. The live site now references repository-local files under `site/assets/images/` instead.

## Commercial-launch requirement

Before treating this website as Manic Espresso's official commercial site:

1. obtain owner-supplied originals for current food, interior, exterior and team photography where Manic Espresso confirms it has commercial web rights; or
2. commission new photography with written commercial-use permission; or
3. obtain explicit permission/licences from the current third-party rights holders for any image retained.

Also re-shoot current food before launch where presentation or menu items may have changed since the historical photographs were taken.

Do not silently substitute Google reviewer, Tripadvisor, Wanderlog, Restaurant Guru, competitor, press or other editorial imagery without confirming reuse rights.
